# PARTHAVI FOREX TRADE DESK PRO 2.0

Independent, prediction-only Forex intelligence dashboard.

## Deploy
This repository is a static website. In Render create a Static Site with:
- Branch: main
- Build command: echo "Publishing PARTHAVI Forex Trade Desk Pro 2.0"
- Publish directory: public

The site opens directly at the dashboard. No broker execution is implemented.
Market values and predictions remain unavailable until a verified provider and backend are configured.

## Brand
Deep navy blue and metallic gold. Original logo is stored under public/assets.
